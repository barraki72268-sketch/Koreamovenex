# 서버에서 노트북 링크 제공하기 — 담당자용

기업 사용자가 서버 링크를 받으면 PC에 Python을 설치하지 않고 브라우저에서 실행할 수 있습니다. **이 저장소 자체는 실행 서버가 아닙니다.** 실제 서버 주소가 준비된 뒤 링크를 전달합니다.

## 1. 운영 형태 선택

- 한 명의 담당자가 시연하는 경우: JupyterLab 한 개로 실행할 수 있습니다.
- 여러 기업 담당자가 동시에 작업하는 경우: **JupyterHub 등 사용자별 계정·작업 공간**을 사용합니다. 하나의 커널과 데이터 폴더를 함께 쓰면 결과나 설정이 서로 섞일 수 있습니다.

공식 안내: [Jupyter Server 운영 가이드](https://jupyter-server.readthedocs.io/en/latest/operators/public-server.html).

## 2. Linux 서버에 기본 환경 준비

Python 3.12와 한글 글꼴을 준비합니다. Ubuntu/Debian 계열이면 전산 담당자가 `fonts-noto-cjk`를 설치하면 됩니다. 아래는 Python 3.12가 준비되어 있다는 전제입니다.

```bash
git clone https://github.com/barraki72268-sketch/Koreamovenex.git
cd Koreamovenex
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip check
.venv/bin/python -m ipykernel install --sys-prefix --name movenex-ect --display-name "Python (Movenex ECT)"
```

실제 회사 CSV는 승인된 경로로 따로 받아 `data/private`에 둡니다. 원본 Excel을 변환해야 할 때는 `data/raw/original`, `data/raw/returned`를 준비합니다. 사용자별 작업 폴더를 분리하고 타 회사 데이터에 접근할 수 없게 계정을 구성합니다.

## 3. 먼저 서버 내부에서 실행 확인

```bash
.venv/bin/python scripts/run_analysis.py --input data/demo/연습용_ECT.csv.gz
.venv/bin/python -m jupyterlab --no-browser --ip=127.0.0.1 --port=8888 --ServerApp.root_dir=. --LabApp.default_url=/lab/tree/notebooks/01_처음부터_분석하기.ipynb
```

기본 실행은 서버 내부 접속입니다. 인증은 Jupyter 기본값을 유지합니다. 외부 접속은 기관의 HTTPS 역방향 프록시 또는 JupyterHub를 통해 연결합니다. 비밀번호/토큰을 끄거나 회사 데이터가 있는 포트를 무인증으로 공개하지 않습니다.

서버 PC가 Windows이면 README의 설치 절차를 적용하고 `start_notebook.cmd`로 내부 실행을 확인할 수 있습니다.

## 4. 링크 구성

단일 JupyterLab을 기관 프록시에 연결한 경우 노트북 경로는 다음 형태입니다. **아래 주소는 예시이며 현재 운영 중인 주소가 아닙니다.**

```text
https://실제-기관-서버/lab/tree/notebooks/01_처음부터_분석하기.ipynb
```

JupyterHub는 사용자별 접두 경로가 붙을 수 있으므로 실제 로그인 후 해당 노트북을 열어 얻은 URL을 전달합니다. README의 GitHub 노트북 링크와 실제 실행 링크를 혼동하지 않도록 ‘내용 미리보기 / 실행하기’를 구분해 전달하세요.

## 5. 기업 사용자에게 전달할 설명

> 전달받은 주소에 로그인한 뒤 `01_처음부터_분석하기.ipynb`를 열어 주세요. 실제 데이터가 준비되었으면 `DATA_MODE = "company"`인지 확인하고, 상단 Run → Run All Cells를 누르시면 됩니다. 마지막 ‘저장 완료’가 나오면 왼쪽 results 폴더에서 보고서와 결과 파일을 내려받을 수 있습니다.

운영자는 전달 전에 회사 모드와 해당 회사 데이터 경로를 설정한 사본을 사용자 폴더에 준비해 둘 수 있습니다. 공개 Git에는 회사 출력이 담긴 실행 노트북을 올리지 않습니다.

## 6. 운영 확인 항목

- 기본 노트북이 처음 칸부터 마지막 저장 칸까지 실행되는지
- 회사/연습 모드가 화면에 명확히 표시되는지
- 사용자별 데이터·모델·결과 경로가 분리되는지
- 한글 그래프가 정상 표시되는지
- 실행 후 CSV·PNG·HTML을 내려받을 수 있는지
- HTTPS와 사용자 인증이 적용되었는지
- 선택 모델을 쓰지 않는 사용자는 PyTorch 없이 기본 실행이 가능한지

토큰이나 비밀번호는 README, Git, 공지용 링크에 기록하지 않습니다. 사용자 관리와 실행 시간·메모리 제한은 기관 서버 정책을 적용하세요.
