# 데이터 폴더

- `demo`: 공개 연습용 합성 데이터입니다. 실제 회사 측정값이 아닙니다.
- `private`: 별도로 전달받은 회사 CSV를 넣습니다. Git에는 올라가지 않습니다.
- `raw/original`: 최초 원본 Excel을 넣습니다.
- `raw/returned`: 기업 판정 표시 회신 Excel을 넣습니다.
- `processed`: Excel에서 새로 변환한 CSV를 저장합니다.

Windows 설치 파일을 실행하면 위 폴더가 준비됩니다. 폴더가 없으면 직접 같은 이름으로 만들어도 됩니다. 파일을 보관만 하고 싶을 때는 GitHub에 업로드하지 않고 기관의 지정된 전달 경로를 사용하세요.
