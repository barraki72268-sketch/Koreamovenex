한국무브넥스 ECT 분석 — 회사 PC용

처음 받았을 때
  1. ZIP 전체를 C:\Movenex 같은 짧은 경로에 압축 해제합니다.
  2. 01_설치.cmd를 더블클릭합니다. 인터넷 연결이 필요합니다.
  3. VS Code도 설치하려면 질문에 Enter를 누릅니다.
  4. 설치 완료가 나오면 02_분석실행.cmd를 더블클릭합니다.

기존 데이터로 분석할 때
  02_분석실행.cmd → 브라우저에서 Run → Run All Cells
  → 자료 종류·학습 파일 선택 → ① 전처리 → ② 학습 → ③ 검사

새 CSV·Excel을 추가할 때
  03_데이터추가_분석.cmd → 자료 종류 선택 → 새 파일 선택
  → 브라우저에서 Run → Run All Cells → ① → ② → ③
  선택한 파일은 복사해서 사용하며 원본은 바꾸지 않습니다.

학습해 둔 화면에서 새 샘플만 계속 검사할 때
  열려 있는 분석 화면의 ③ 새 검사 파일 올리기를 사용하세요.
  학습한 모델과 PCA를 유지하고 ③번만 반복할 수 있습니다.
  03번 CMD는 새 분석 화면을 준비하는 용도입니다.

이 프로그램은 회사 PC에서 실행합니다. NAS·연구실 서버 연결은 필요 없습니다.
실행 창을 닫으면 노트북 실행도 종료됩니다.
데이터: data/private    결과: results    설치 오류 로그: logs

GitHub에서 받은 일반 ZIP에는 실제 회사 데이터가 포함되지 않습니다.
