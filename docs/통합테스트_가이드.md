# 학습하고 새 샘플을 반복 검사하는 방법

09번은 학습 파일을 한 번 준비하고, 같은 모델로 새 샘플을 계속 검사하는 화면입니다. Python 코드를 입력할 필요는 없습니다.

`학습 파일 선택 → ① 전처리 → ② 학습 → 새 검사 파일 → ③ 검사 → 다음 파일도 ③ 반복`

## 화면 준비

담당자가 전달한 인증 링크로 접속합니다. 왼쪽 notebooks에서 `09_통합테스트_샘플별결과.ipynb`를 열고 `Run → Run All Cells`를 한 번 누릅니다. 아래에 ①·②·③ 화면이 나타납니다. 로그인 정보는 담당자에게 개별 전달받아 사용합니다.

## ① 학습 데이터 넣기

1. 자료 종류를 고릅니다. 기존 C10 열처리 ECT, 크랙, 샤프트를 지원합니다. 기존 C80B도 기존 ECT 형식으로 선택할 수 있습니다.
2. 학습 파일 올리기를 누르거나 학습 파일 목록에서 서버 파일을 고릅니다.
3. `① 데이터 읽기 · 전처리`를 누릅니다.
4. 수량표의 품번·위치, 유효행, MASTER·기업 진성·기업 가성, 사용 입력 수를 확인합니다.

| 자료 | 권장 입력 |
|---|---|
| 기존 C10/C80 ECT | 기업 라벨이 연결된 표준 .csv.gz 또는 기존 106컬럼 Excel |
| 크랙 | 전달받은 크랙 원본 .xlsx |
| 샤프트 | 전달받은 샤프트 원본 .xlsx |

샤프트는 기본으로 학습 데이터의 +100 측정값·32767 포화 의심 채널을 제외합니다. 해당 주파수의 X/Y·측정값을 함께 제외합니다. 모든 100 이상 값을 자르는 방식은 아닙니다. 이후 새 샘플이 와도 제외 기준을 새로 정하지 않습니다. 최대값 0, 라벨 충돌, 결측은 확인 대상으로 남깁니다.

학습 기간을 제한하려면 필요할 때만 항목을 펼쳐 학습 종료일을 입력합니다. 빈칸이면 선택한 학습 파일 전체를 사용합니다. 크랙은 기본 오전 6시를 검사일 경계로 사용합니다. 학습 파일의 경계 이후 첫 측정이 MASTER 후보이며, 설비 OK와 충돌하면 양성 참조로 쓰지 않습니다. 새 검사 파일 첫 행을 임의로 진성 정답으로 지정하지 않습니다.

## ② 모델 학습하기

1. 기본 Random Forest 또는 XGBoost를 고릅니다.
2. `② 모델 학습`을 누릅니다.
3. 학습 완료와 품번·위치별 수량표를 확인합니다. 학습 PCA에서 볼 품번·위치를 고릅니다.

이 단계에서 입력 컬럼, 포화값 제외 기준, 모델, PCA와 점수 기준이 고정됩니다. PCA는 측정값의 분포를 두 축으로 요약한 그림입니다. 학습 분포이며, 새로운 날짜에 대한 정확도를 보여주는 그림은 아닙니다.

기업 진성 라벨이 있는 구간은 해당 라벨과 정상·기업 가성 자료로 학습합니다. 진성 라벨이 없는 구간은 MASTER와 설비 OK·가성을 참조한 유사성 모델로 학습합니다. 수량표의 학습기준에서 구분합니다. 두 종류의 학습 예시가 없거나 입력이 부족하면 학습 불가 사유를 남깁니다. 품번·위치는 서로 섞어 학습하지 않습니다.

학습 모델·벡터 입력 양식 ZIP 다운로드를 누르면 모델, 학습 기준, 품번·위치별 CSV 양식을 저장합니다. 실제 데이터로 학습한 모델은 공개 GitHub에 올리지 않습니다.

이 화면은 CPU에서 실제 재학습·예측하는 RF·XGBoost입니다. 이전 TabICLv2 저장 GPU 그림을 새 샘플의 예측 결과로 쓰지 않습니다. 저장 GPU 실험과 이전 일괄 분석은 10번 연구용 화면에 보존했습니다.

## ③ 새 샘플 배치 검사하기

1. 새 검사 파일 올리기를 누르거나 검사 파일 목록에서 새 파일을 고릅니다.
2. `③ 새 샘플 배치 검사`를 누릅니다. 여러 행을 품번·위치별 벡터 묶음으로 처리합니다.
3. 판정 수량표, PCA 위치, 샘플별 점수를 확인합니다.
4. 다음 파일을 넣고 ③번만 다시 누릅니다. 학습 파일·설정을 바꾸지 않았다면 ①·②를 반복할 필요가 없습니다.

새 검사 데이터로 모델이나 PCA를 다시 학습하지 않습니다. PCA의 회색 배경은 고정한 학습 분포, 색이 있는 점은 이번 샘플의 예측입니다. 좌표도 CSV에 저장됩니다. 표시 범위는 새 샘플에 맞춰 달라질 수 있지만 PCA 축 자체는 고정입니다.

| 판정 | 읽는 방법 |
|---|---|
| 정상 유사 | 모델 점수가 낮은 설비 OK 또는 설비 판정 미입력 샘플 |
| 가성불량 후보 | 모델 점수가 낮은 설비 NG. 현장 확인 필요 |
| 진성불량 의심 | 모델 점수가 높은 설비 NG 또는 판정 미입력 샘플 |
| 불량 의심 · FN 후보 | 설비 OK이지만 모델 점수가 높은 샘플. 실제 FN 확정은 정답 확인 후 가능 |
| 판정 보류 | 점수가 두 기준 사이이거나 학습 뒤 새 포화값이 나온 샘플 |
| 입력 확인 필요 | 학습하지 않은 품번·위치, 다른 주파수, 결측·오류 등으로 예측하지 않은 행 |

기본 낮음·높음 기준은 0.1과 0.9입니다. 점수는 실제 불량 확률로 보장되지 않습니다. MASTER 유사성 모델의 낮은 점수만으로 새로운 불량 유형까지 배제할 수는 없습니다. 실제 처분은 현장 검사와 확인합니다.

결과 보기·검색·페이지로 샘플을 찾습니다. 학습 파일과 중복된 행은 검증구분에 표시되며 독립 시험 성능으로 보지 않습니다. 정답 없는 새 샘플의 정확도나 FN 수를 임의로 계산하지 않습니다.

## 한 행 또는 벡터 CSV로 검사하기

학습 후 내려받은 `벡터입력양식_01.csv` 등을 Excel에서 엽니다. 라인·품번·위치 값과 측정 컬럼 이름을 유지하고 실제 측정값을 채웁니다. 빈 측정값을 채우지 않은 양식 자체는 유효한 검사 샘플이 아닙니다.

- sample_id: 각 행의 고유 이름. TEST_001, TEST_002처럼 서로 다르게 적습니다.
- line/product/position: 학습한 라인·품번·위치. 양식에 입력된 값을 확인합니다.
- equipment_label: 설비 판정 OK 또는 NG. 빈칸이면 FN/가성 구분에 사용할 설비 판정이 없는 것으로 처리합니다.
- date/time/counter: 알면 원본 검사일·시각·검사번호를 적습니다.
- max_value: 최대측정값. 0이면 판정 불명으로 남깁니다.
- feature__...: 학습 모델에 필요한 측정값. 컬럼 이름을 바꾸지 않습니다.
- label: 학습용 정답을 넣을 때만 normal/master/true/false/unknown을 사용합니다. 새 검사에서 정답이 없으면 unknown으로 둡니다.

CSV UTF-8로 저장해 새 검사 파일 올리기로 넣습니다. 벡터 CSV를 붙여넣어 검사 항목을 펼쳐 헤더와 여러 행을 그대로 붙여넣어도 됩니다. 붙여넣기 내용이 있으면 선택 파일보다 우선 사용합니다. 파일을 검사하려면 붙여넣기 칸을 비우세요.

## 저장과 재학습

이번 배치의 결과·PCA·전체 샘플 CSV 다운로드를 누릅니다. 압축을 풀고 `배치검사_보고서.html`을 엽니다. `샘플별_예측결과.csv`에는 제외행을 포함한 모든 입력 행과 점수·판정·PCA 좌표·중복 여부가 들어 있습니다. 검사할 때마다 새 폴더를 만들어 원본과 이전 결과를 덮어쓰지 않습니다.

학습 파일·자료 종류·전처리·학습 기간을 바꾸면 ①·②를 다시 실행합니다. 모델 종류나 점수 기준만 바꾸면 ②를 다시 실행합니다. 검사 파일만 바꾸면 ③만 반복합니다. 커널을 다시 시작했다면 ①·②부터 준비합니다.
