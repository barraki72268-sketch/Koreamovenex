# 추가 데이터가 왔을 때 따라 하기

이 문서는 ‘데이터가 더 왔을 때 무엇을 바꾸면 되는가’를 설명합니다. 원본을 수정하지 않고 새 CSV와 결과를 별도 저장합니다.

## 1. 먼저 받은 자료를 구분하세요

| 받은 자료 | 처리 |
|---|---|
| 최초 원본 Excel + 색상으로 판정한 회신 Excel | 아래 2번대로 연결하여 CSV 생성 |
| 이번 프로그램용 표준 CSV | 3번으로 이동 |
| 최대측정값만 따로 추린 표 또는 컬럼 순서가 다른 Excel | 담당자가 형식을 확인한 뒤 변환. 그대로 실행하지 않음 |
| 판정 없는 원본 | 진성/가성을 임의로 붙이지 않음. 같은 형식의 ‘unlabeled’ CSV로 변환 후 마스터 기준 참고 분석 가능 |

## 2. Excel에서 CSV 만들기

현재 변환기는 제공된 **106컬럼·앞 2행 헤더 ECT 템플릿**을 읽습니다. Excel을 설치하지 않아도 변환됩니다.

1. 최초 원본을 `data/raw/original`에 넣습니다.
2. 기업이 판정 표시한 같은 품번 회신본을 `data/raw/returned`에 넣습니다.
3. 두 파일의 이름이 같은지 확인합니다. 예: `C10A_49513-75270R.xlsx`.
4. [02번 노트북](../notebooks/02_추가데이터_변환과_재학습.ipynb)을 열고 ①의 품번을 확인합니다.
5. ② ‘Excel → CSV 변환’ 칸을 실행합니다.
6. `data/processed`에 CSV와 `.provenance.json`이 생성됩니다.
7. 표시된 위치별 진성·가성·마스터 수량을 기업 회신과 대조합니다.

**행 번호가 같은지만 보고 연결하지 않습니다.** 측정값이 같은지 먼저 확인합니다. 회신에서 카운터가 메모로 바뀔 수 있어 카운터를 연결 키에서 제외합니다. 시간을 수정한 행은 시간·카운터를 제외한 측정값이 양쪽 모두에서 유일할 때만 연결합니다. 연결되지 않거나 라벨이 충돌하면 자동 학습에 사용하지 않습니다.

### 현재 회신본의 색상 규칙

| 회신 표시 | CSV의 `field_label` | 의미 |
|---|---|---|
| 카운터/시간에 ‘마스터’ 표기 | `NG_master` | 기업이 식별한 NG 마스터 |
| 밝은 주황색 `FFFFC000`, 설비 NG | `field_true` | 기업 진성 |
| 초록색 theme 9 | `field_false` | 기업 가성 |
| 회색 또는 최대값 100, 오류 메모 | `measurement_error` | 측정 오류, 제외 |
| 0 또는 원본의 노란색 | 라벨과 별도로 `yellow_any`/최대값 확인 | 판정 불명, 제외 |
| 옅은 노란 계열 theme 7 | `reference_marker` | 참고 표시, 진성으로 간주하지 않음 |
| 주황색인데 설비 OK | `color_on_OK_unverified` | 확인 필요, 학습 제외 |
| 표시 없음 | `unlabeled` | 기업 진성/가성 미확인 |

색상 표시는 회신본의 특정 Excel 스타일에 맞춘 규칙입니다. 새로운 파일에서 색상·컬럼·템플릿이 바뀌면 담당자가 규칙을 확인해야 합니다. 회색 오류 판정은 마스터보다 우선합니다. 마스터의 미열처리/크랙 종류는 별도 구분 자료가 없어 추정하지 않습니다.

## 3. CSV에는 어떤 정보가 있나요?

**한 줄은 한 위치의 측정행입니다.** 위치 1/2를 한 줄로 합치지 않습니다.

| 컬럼 | 설명 |
|---|---|
| `date`, `time` | 검사 날짜·시각. 날짜는 `YYYY-MM-DD` |
| `counter` | 검사 카운터 또는 기업 메모. 실제 제품 ID로 확정하지 않음 |
| `line`, `product`, `part_no` | 원본의 라인·제품·품번 정보 |
| `equipment_label` | 설비 판정 `OK` / `NG` |
| `position` | 검사 위치 `1` / `2` |
| `max_value`, `max_frequency` | 원본 최대 측정값·주파수. 모델 입력으로 사용하지 않음 |
| `freq_1` ~ `freq_24` | 각 슬롯의 주파수 이름 |
| `x_1`, `y_1` ~ `x_24`, `y_24` | 모델의 실제 입력 X/Y 값 |
| `spear_1` ~ `spear_24` | 원본 보조 측정값. 이번 모델 입력에서는 제외 |
| `source_file`, `source_sheet`, `source_row` | 최초 원본 파일·시트·행 번호 |
| `yellow_any` | 원본에 노란 표시가 있으면 `True`, 없으면 `False` |
| `field_label` | 기업 판정 코드. 위 표 참고 |
| `field_row`, `field_sheet`, `mapping_status` | 회신본의 위치와 연결 상태. 자동 변환 시 생성 |

기존 형식은 원본 106개 컬럼과 위 출처·라벨 컬럼을 유지합니다. 모델이 쓰는 값은 활성 주파수의 X/Y뿐입니다. 변환한 CSV를 Excel에서 열어 다시 저장하면 날짜·식별자 형식이 바뀔 수 있으므로 변환본은 그대로 사용하는 편이 좋습니다.

진성·가성을 아직 모르는 새 NG는 `field_label=unlabeled`로 둡니다. 다른 위치의 판정을 복사하지 않습니다. 기업이 확인하지 않은 결과를 모델 결과로 덮어쓰지 않습니다. 라벨이 없어도 저장 모델로 점수를 낼 수 있으며, 라벨 비교 수량에는 포함하지 않습니다.

## 4. 기존 파일에 추가할지, 교체할지

### 전체 회신본이면 교체

8월 데이터와 10월 데이터가 모두 들어 있는 회신본을 받았다면 기존 CSV에 또 더하지 않습니다. 새로 변환한 전체 CSV 하나를 선택합니다. 기존 행의 판정만 수정한 경우도 새 변환본으로 교체합니다.

### 새 날짜 추가분이면 합치기

02번 노트북 ③에서 `MERGE_FILES = True`로 바꿉니다. `BASE_CSV`, `NEW_CSV`가 맞는지 확인하고 실행합니다.

같은 `source_file + source_sheet + source_row + position`이 있으면 중단합니다. 중복을 자동으로 삭제하지 않습니다. 같은 원본이 다시 들어온 것인지 확인합니다. 서로 다른 날짜 파일의 시트명·행번호가 같다면 원본 파일명을 날짜 포함 고유 이름으로 관리하는 등 담당자가 출처 ID를 먼저 정리해야 합니다.

한 CSV에는 **한 품번**, 각 위치에는 **일관된 주파수 구성**이 필요합니다. 다른 품번이나 설비 조건을 한 CSV에 섞지 마세요.

## 5. 추가 데이터를 학습에 쓰기

02번 노트북 ④에서 `TRAINING_CSV`를 새 CSV 또는 누적 CSV로 지정합니다.

```python
TRAINING_CSV = NEW_CSV
TRAIN_END = "2026-08-20"
CALIBRATION_END = "2026-10-07"
```

이 설정은 기존 결과 재현용입니다. 예를 들어 11월 데이터가 추가되었다면, 실제 가지고 있는 날짜와 수량을 먼저 확인하고 **학습 종료일 < 기준 설정 종료일 < 시험 날짜**가 되도록 바꿉니다. 시험용 데이터를 모두 학습에 넣으면 새로운 날짜 검증이 사라집니다.

재학습은 새 모델을 만드는 동작입니다. `models`와 설정이 새 결과 폴더에 저장되므로 이전 모델과 비교할 수 있습니다. 기업 진성이 학습에 포함되었는지는 결과의 `in_training`으로 확인합니다.

## 6. 학습하지 않고 새 CSV에 적용하기

02번 노트북 ⑤에서 두 경로를 지정합니다.

```python
MODEL_PATH = ROOT / "results/실행폴더명/models/p2_master_proxy_XGBoost.joblib"
INFERENCE_CSV = NEW_CSV
```

이 모델은 위치 2 전용입니다. 위치 1은 위치 1 모델로 별도 적용합니다. 새 CSV에 양쪽 위치가 있어도 선택한 모델과 같은 위치만 처리합니다. 주파수·블록 구성이 다르면 중단합니다.

`distance_reference.joblib`은 거리 기준 보관용입니다. ⑤의 저장 모델 적용에서는 `p1_...RandomForest.joblib`, `p2_...XGBoost.joblib`처럼 위치별 분류 모델을 선택합니다. 거리 기준은 ①~④ 또는 01번 노트북에서 재현합니다.

새 데이터의 설비 NG 중 유효한 행만 점수를 냅니다. OK·마스터·오류·0/노랑·라벨 연결 오류는 ‘분석 대상 아님’으로 표시합니다. `unlabeled` NG는 최종 라벨이 없어도 점수화합니다. 결과 CSV는 `results/새데이터_모델적용_시각.csv`에 저장합니다.

`.joblib`은 직접 저장한 신뢰할 수 있는 모델만 불러옵니다. 외부에서 받은 출처 불명 파일을 열지 않습니다.

## 7. 전달하기 전 확인

1. 회사 데이터 모드로 실행했는지 확인합니다.
2. 위치별 입력 수, 제외행, 라벨 수량을 확인합니다.
3. 전체 NG와 시험 날짜 NG 결과를 구분합니다.
4. 진성이 몇 행이며 학습에 포함되었는지 확인합니다.
5. 진성 0행인 시험 구간을 진성 검출률 100%로 보고하지 않습니다.
6. 결과 폴더 전체를 별도로 전달합니다. 데이터·실행 결과는 Git에서 제외됩니다.
